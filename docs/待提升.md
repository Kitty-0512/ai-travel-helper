## 2. 线上持久化：本地降级 ≠ 线上也降级

本地没开 Redis / PostgreSQL 时，会自动降级：

- 会话 → 写到 `backend/data/sessions.json`  
- 记忆 / 限流 / 轨迹 → 内存里凑合用  

**这只影响本机。**  
你要上线完整保存「对话 / 行程记录」，Render 上还是得挂真库：

| 要啥 | 用啥 |
|------|------|
| 历史会话不丢 | PostgreSQL（必上） |
| 用户长期偏好 | PostgreSQL（最好带 pgvector）+ Redis |
| 限流跨重启还准 | Redis |
| Agent 执行轨迹 | PostgreSQL |

生产环境还得关掉内存兜底（`MEMORY_FALLBACK_INPROCESS=false`、`TRACE_FALLBACK_INPROCESS=false`），否则 `ENV=production` 可能直接起不来。

表结构要手动跑一遍 `backend/sql/` 下面那几个 SQL（Render 不会自动帮你跑 docker-compose 的初始化脚本）。
